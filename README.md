# 장서점검 분석 리포트

현장 스캔과 등록원부의 등록번호를 비교하고, 2차 조사와 제적 검토 내역을 정리하는 단일 HTML 도구입니다.

- [사이트 열기](https://daeung79.github.io/BookScan/)
- 첫 화면에는 2026년 10월 29일 서창도서관 샘플의 분석 결과가 표시됩니다.
- 오른쪽 위 **엑셀 등록**으로 다른 `.xlsx`, `.xls`, `.csv` 파일을 분석할 수 있습니다.
- 부족한 숫자 자리수는 영문 접두어와 숫자 사이에 `0`을 넣어 등록원부 형식에 맞춥니다.
- 재스캔과 조치 기록은 사용 중인 브라우저에 저장되며, 목록을 CSV로 내려받을 수 있습니다.

분석은 브라우저에서 실행됩니다. 업로드한 파일은 서버로 전송되지 않습니다. 샘플 데이터는 `index.html`에 포함되어 있으므로 공개 저장소 및 GitHub Pages에서 볼 수 있습니다.
